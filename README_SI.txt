SPIDER AI — AROSH EDITION

This is an Android Studio project for an offline, full-screen Spider HUD home screen.
Features in this starter build:
- Spider-inspired HUD layout, dark circuit background, neon blue/red panels
- Health, web-fluid, suit status and environment display (sample/demo values)
- J.A.R.V.I.S assistant panel greeting Arosh
- Native Android text-to-speech for the JARVIS buttons
- Portrait layout and offline assets

BUILD THE APK
1. Install Android Studio on a computer.
2. Open this SpiderAI folder in Android Studio.
3. Allow Gradle sync and install Android SDK Platform 35 if Android Studio asks.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. The debug APK will be created at app/build/outputs/apk/debug/app-debug.apk.

IMPORTANT
- This folder is the Android app source project, not a compiled APK. This environment does not have the Android SDK/Gradle build setup needed to compile and sign an APK.
- Health, armor, altitude, temperature and web-fluid values are illustrative demo values, not readings from real sensors or a real Spider-Man suit.
- JARVIS voice output uses the Android device's installed Text-to-Speech voice. It is a local demo assistant, not a connected AI service.
